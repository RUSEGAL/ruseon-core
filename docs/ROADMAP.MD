- [x] Инъекция заглушек в HLS-буфер (Failover для сторонних плееров: VLC, OBS и др. Вставка статичного кадра «Потеря сигнала» при обрыве связи с камерой на бэкенде).
- [x] Ленивый HLS (Lazy Muxing) (Опциональный переключатель. Остановка генерации HLS-сегментов при отсутствии зрителей для экономии ресурсов. Архитектура: полное уничтожение HLS Muxer'а во время сна и его мгновенное пересоздание при запросе с быстрой "промоткой" истории из RingBuffer для моментальной генерации первых TS-сегментов без задержки перед стартом видео).
- [ ] WebRTC (Для ультра-низкой задержки воспроизведения <0.5 сек)
- [ ] Дополнительные модули (PTZ-управление ONVIF)
- [x] Защита от сбоев питания (Сканирование и восстановление/«лечение» незавершенных MP4-файлов архива при резком отключении сервера).
- [x] Hotfix: Доступ к Timeshift архиву. (Сейчас архив доступен для просмотра только если в настройках камеры стоит галочка "Record". Нужно разрешить просмотр архива в любом случае, если на диске физически существуют .mp4 файлы для данной камеры).

- [ ] Сайдбар событий / Журнал активности (UI/UX: Выезжающая панель с real-time лентой системных событий, уведомлениями об отключениях и подключениях камер).
- [ ] Группировка и "Папки" для камер (UI/UX: Визуальное разделение и сворачивание списков камер по группам/тегам для удобной навигации при большом количестве устройств).
- [x] Настройка RTSP Транспорта (TCP/UDP/Auto) (Добавление в БД и UI возможности выбора протокола для каждой камеры. TCP по умолчанию для исключения артефактов (зеленых квадратов), UDP для совместимости со старыми устройствами).

## Тесты

Покрытие кода тестами на данный момент составляет **16.2%**. Ниже приведен план покрытия тестами модулей по приоритетам.

### 🔴 Критический приоритет (Ядро и стриминг)
- [ ] **RTSP Клиент (`internal/rtsp/client.go`)**: Тестирование подключения, обработки разрывов сети и функции `Start` (прием NALU кадров).
- [ ] **MP4 Рекордер (`internal/recorder/recorder.go`)**: Проверка корректной записи `fMP4` чанков, ротации файлов и безопасного завершения (`Stop`).
- [ ] **Чтение архива и HLS (`internal/archive/hls.go`)**: Проверка генерации `m3u8` плейлистов из файлов архива и нарезки MP4 на TS-сегменты "на лету" (`GenerateHLSSegment`).
- [ ] **Поток камеры (`internal/stream/stream.go`)**: Тестирование логики `run()` (реконнекты RTSP), Lazy HLS (watchdog и `WakeUpHLSMuxer`) и сбора статистики.

### 🟠 Важный приоритет (Хранение, целостность и очистка)
- [ ] **База данных и Бэкапы (`internal/storage/storage.go`, `internal/backup/worker.go`)**: Тестирование CRUD для тегов, экспорта/импорта конфигураций JSON, фоновых дампов БД.
- [ ] **Очистка и Восстановление (`internal/recorder/cleanup.go`, `recovery.go`)**: Проверка автоматического удаления старых записей (retention) и "лечения" поврежденных (незавершенных) `mdat` атомов в `.mp4` после сбоев питания.

### 🟡 Средний приоритет (API, Экспорт и Биллинг)
- [ ] **API Обработчики (`internal/api/handler.go`)**: Интеграционные тесты для эндпоинтов авторизации, CRUD камер/тегов и отдачи плейлистов/сегментов.
- [ ] **Экспорт архива (`internal/archive/export.go`, `indexer.go`)**: Тестирование логики поиска временных интервалов и точной склейки MP4-отрезков по времени (`startSeq`, `endSeq`).
- [ ] **Биллинг трафика (`internal/stream/billing.go`)**: Проверка корректного вычитания использованных байт из лимита камер и сброса биллинга 1-го числа месяца.

### 🟢 Низкий приоритет (Роутер, Логирование, Инфраструктура)
- [ ] **Логгер и SSE-бродкастер (`internal/logger`)**: Тесты перехвата логов и подписки/отписки клиентов (SSE).
- [ ] **Роутинг и Main (`internal/api/router.go`, `cmd/server/main.go`)**: Тестирование инициализации зависимостей, middleware (CORS, Recover) и graceful shutdown сервера.
