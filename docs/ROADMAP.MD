# Дорожная карта (Roadmap) RUSEON Core

## Завершенные этапы (Фундамент MVP)
- [x] **Этап 1-27: Базовая архитектура, HLS, fMP4, Web UI, BadgerDB, Zero-Copy RingBuffer, i18n** (Подробнее в истории коммитов).
- [x] **Этап 28: Защита от шторма подключений (Thundering Herd)** (Реализация Singleflight паттерна для массовых запросов HLS).
- [x] **Этап 29: Защита от утечек памяти (OOM Mitigation)** (Троллинг медленных клиентов, неблокирующие каналы с умным дропом кадров, жесткие таймауты HTTP).

## Текущий статус: Этап 30 (Развитие Enterprise & AI Pipeline)

- [ ] **Этап 30: Поддержка WebRTC (WHEP / WHIP)** (Ультра-низкая задержка <500мс для PTZ-управления и реалтайм аналитики через библиотеку `pion/webrtc`).
- [x] **Этап 31: Оптимизация дискового I/O (Direct I/O)** (Использование флагов `O_DIRECT` в Linux при записи fMP4 архива для обхода кэша ОС (Page Cache) и спасения оперативной памяти).
- [ ] **Этап 32: Метаданные поверх видео (Bounding Boxes)** (gRPC стриминг данных от ИИ-модулей в ядро и внедрение их как субтитры `WebVTT` или SEI-сообщения H.264 для отрисовки "квадратиков" детекции на клиенте без транскодинга).
- [ ] **Этап 33: Система Push-событий (Event Bus)** (Рассылка Webhooks, MQTT или NATS событий: `camera_offline`, `archive_segment_ready` для мгновенной реакции внешних систем).
- [ ] **Этап 34: Наблюдаемость (Prometheus / Grafana)** (Внедрение эндпоинта `/metrics` с экспортом количества горутин, аллокаций памяти, зрителей HLS, счетчиков Drops для Grafana-дашборда).
- [ ] **Этап 35: Token-Based Authentication для HLS** (Stateless проверка JWT-токенов в URL плейлистов `?token=...` на лету для защиты потоков от несанкционированного доступа).
- [ ] **Этап 36: Fuzzing-тесты для RingBuffer** (Chaos тестирование ядра: запуск 1000 конкурентных писателей и 10000 читателей для гарантии абсолютной потокобезопасности без дедлоков).

## RUSEON Enterprise (ruseon-enterprise)
Помимо базового ядра, следующие функции выделены в проприетарную ветку:
- [ ] **Global High Availability (Clustering)** (Синхронизация стейта через Raft, автоматический Failover (миграция) камер при падении сервера-ноды).
- [ ] **GPU Transcoding (NVENC)** (Перекодирование адаптивного битрейта для мобильных клиентов через аппаратное ускорение Nvidia CGO).
- [ ] **S3 Cold Storage Tiering** (Прозрачная и автоматическая выгрузка старых fMP4-записей (старше 7 дней) с быстрого NVMe в Amazon S3 / Minio).
