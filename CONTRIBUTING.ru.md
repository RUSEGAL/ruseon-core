# Участие в разработке RUSEON Core

*Читать на других языках: [English](CONTRIBUTING.md), [Русский](CONTRIBUTING.ru.md).*

Спасибо за ваш интерес к участию в разработке RUSEON Core! Мы приветствуем любой вклад сообщества, чтобы сделать нашу Cloud-Native платформу для видеоданных еще лучше.

## Как внести свой вклад

1. **Fork и Branch**: Сделайте форк репозитория и создайте новую ветку от `dev` (например, `feat/new-feature` или `fix/bug-name`).
2. **Предварительное обсуждение**: Для крупных фич или ломающих изменений, пожалуйста, сначала откройте Issue для обсуждения ваших идей, прежде чем писать код.
3. **Написание кода**: Внесите свои изменения. Убедитесь, что вы следуете стандартам кодирования проекта.
4. **Тестирование**: Напишите тесты для ваших изменений. Выполните `go test -race ./...`, чтобы убедиться в отсутствии ошибок.
5. **Линтинг**: Запустите `golangci-lint run`, чтобы проверить код на соответствие нашему стилю.
6. **Коммиты**: Используйте [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/) для ваших сообщений коммитов.
7. **Отправка PR**: Откройте Pull Request с целевой веткой `dev`.

## Правила написания коммитов

Мы следуем спецификации Conventional Commits. Пожалуйста, структурируйте ваши коммиты следующим образом:

```text
<type>[optional scope]: <description>

[optional body]

[optional footer(s)]
```

**Разрешенные типы (type):**
- `feat`: Новая функциональность
- `fix`: Исправление бага
- `docs`: Только изменения в документации
- `style`: Изменения, не влияющие на смысл кода (пробелы, форматирование и т.д.)
- `refactor`: Рефакторинг кода (не исправляет баг и не добавляет фичу)
- `perf`: Изменения, улучшающие производительность
- `test`: Добавление отсутствующих или исправление существующих тестов
- `chore`: Изменения в процессе сборки или вспомогательных инструментах
